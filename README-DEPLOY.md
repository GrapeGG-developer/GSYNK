# GSYNK — сайт проекта + веб-версия

Готовый статический сайт для GitHub Pages (или любого статического хостинга):
лендинг со скачиванием Android APK и настоящая веб-версия в браузере.
Логотип **GrapeScript (.lottie)** — в правом нижнем углу каждой страницы.

## Что внутри

| Файл / папка | Что это |
|---|---|
| `index.html` | Главная: фирменный Metro-стиль, аврора-фон, живой «островок» (часы + заряд), телефон с плитками, фишки, каталог 79 плиток с поиском и фильтрами, 14 пунктов GSUI V4, скачивание APK (кнопка + QR + SHA-256), FAQ, пасхалка по пяти кликам на иконку |
| `app.html` | **Веб-версия GSYNK**: главная с плитками и избранным, редактор правил яркости/громкости, стенд-бенчмарк + нагрузка ядрами, эхо-линейка (тот же принцип разбора записи, что в приложении), проверка глаз (Ландольт с калибровкой по карте + цветные пластины), пульс камерой, тон/мелодии, фонарь/строб/морзянка, профиль устройства, «каждый день» |
| `404.html` | Фирменная страница «такой плитки нет» |
| `manifest.webmanifest` + `sw.js` | Веб-версию можно поставить как приложение (PWA): иконка, офлайн-оболочка |
| `assets/grapescript.lottie` | **Логотип GrapeScript** (dotLottie: `manifest.json` + `animations/grapescript.json`), играет в правом нижнем углу |
| `assets/grapescript.png` / `grapescript.json` | Статичный запасной логотип и та же анимация обычным Lottie JSON |
| `assets/js/grapescript-badge.js` | Загрузчик: распаковывает .lottie в браузере (fflate) и играет через lottie-web; обе библиотеки лежат рядом, сеть не нужна |
| `assets/qr-apk.png` / `.svg` | QR на прямой APK 4.0.4 из релизов GitHub |
| `assets/icon-*.png`, `favicon.ico` | Фирменная иконка GSYNK из `branding/` |
| `.nojekyll` | Чтобы GitHub Pages не трогал файлы джекиллом |

Ссылка на APK **самообновляется**: при открытии сайт спрашивает GitHub API о последнем
релизе `GrapeGG-developer/GSYNKAPP` и подставляет свежую ссылку и версию (как фирменная
проверка обновлений в самом GSYNK). Если API недоступен — остаётся закреплённая 4.0.4.

## Деплой на GitHub Pages — 3 минуты

Вариант А (рекомендуется: отдельный репозиторий, чтобы не мешать с исходниками Android):

1. Создай репозиторий, например `gsynk-site` (или `GrapeGG-developer.github.io` — тогда сайт встанет в корень домена).
2. Распакуй этот архив и залей **всё содержимое** в корень репозитория (через git push или «Add file → Upload files» на GitHub; папку-обёртку не создавай — `index.html` должен лежать в корне).
3. Открой репозиторий → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт живёт по адресу `https://grapegg-developer.github.io/gsynk-site/` (или `https://grapegg-developer.github.io/`).

Вариант Б (тот же репозиторий GSYNKAPP): создай ветку `gh-pages`, залей туда содержимое
архива и в Settings → Pages выбери эту ветку. В `main` сайта не клади: там исходники Android и папка `docs/` уже занята документацией проекта.

Свой домен: положи в корень файл `CNAME` с одной строкой домена и наведи DNS по инструкции GitHub Pages.

Проверка перед деплоем локально:

```bash
cd gsynk-site
python3 -m http.server 8000
# открыть http://localhost:8000 — НЕ через file://: загрузчику .lottie и PWA нужен http(s)
```

## GrapeScript: как поставить ОРИГИНАЛЬНЫЙ .lottie

Ссылка на `tmpfiles.org` к моменту сборки уже протухла (сервис живёт десятки минут и
отдавал 404 на прямой файл), поэтому логотип собран заново в фирменном градиенте
проекта и упакован как настоящий dotLottie. Если у тебя есть свой оригинал — заменить его легко:

1. Просто перезапиши файл `assets/grapescript.lottie` своим. Код трогать не нужно.
2. Загрузчик понимает: настоящий dotLottie (zip + `manifest.json` + `animations/*.json`, внешние картинки из архива подхватываются) и обычный Lottie JSON, переименованный в `.lottie`.
3. При желании обнови и `assets/grapescript.png` — это статичный запасной вариант на случай, если анимация не загрузится (например, при `prefers-reduced-motion`).

## Когда выйдет GSYNK 4.0.5+

- Кнопки сами подхватят свежий релиз с GitHub (если имя ассета заканчивается на `.apk`).
- Вручную стоит обновить три «закреплённых» места поиском по `v4.0.4`: ссылки в `index.html` и `app.html`, строку SHA-256 на главной и QR-код (`assets/qr-apk.png`) — он сгенерирован на прямой файл 4.0.4. Перегенерировать QR можно одной командой: `python3 -c "import segno; segno.make('ССЫЛКА_НА_APK').save('assets/qr-apk.png', scale=10, border=2, dark='#2a1454')"`.

## Честность веб-версии

Веб-версия не изображает работу, а работает: правила сохраняются и применяются к демо-экрану
и звуку, бенчмарк правда крутит циклы, эхо разбирает синтетическую запись по тому же принципу,
что и приложение, пульс считает автокорреляцией кадра камеры. Функции, которые браузеру
запрещены (NFC, системная яркость, островок поверх приложений, датчики железа), никогда
не притворяются — плитка честно ведёт к APK.
